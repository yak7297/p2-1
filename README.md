## 🏗️ 3. 주요 함수와 역할

각 기능이 꼬이지 않도록 역할별로 하나씩 나누어 작성했습니다.

* `display_menu()`: 화면에 선택할 수 있는 메뉴판을 보여줍니다.
* `add_prompt()`: 새로운 프롬프트(제목, 내용, 카테고리)를 등록합니다.
* `list_prompts()`: 등록된 모든 프롬프트를 목록으로 출력합니다.
* `view_by_category()`: 사용자가 선택한 카테고리의 글만 모아서 보여줍니다.
* `search_prompts()`: 제목이나 내용에 내가 입력한 단어가 들어있는지 검색합니다.
* `view_prompt_detail()`: 특정 프롬프트의 전체 내용을 자세히 보여줍니다.
* `toggle_favorite()`: 즐겨찾기 상태(★/☆)를 켜거나 끕니다.
* `list_favorites()`: 즐겨찾기(★) 해둔 중요한 프롬프트만 골라서 보여줍니다.
* `main()`: 사용자가 종료(0번)를 누를 때까지 메뉴를 계속 띄우고 입력을 처리합니다.

## 📊 4. 데이터 저장 방식과 구조

### ■ 리스트와 딕셔너리를 사용한 이유
* 프롬프트를 순서대로 차곡차곡 보관하기 위해 **리스트**를 사용했습니다.
* 프롬프트 1개 안에 들어가는 '제목', '내용', '카테고리' 같은 정보들을 이름표를 붙여 깔끔하게 묶어두기 위해 **딕셔너리**를 사용했습니다.

### ■ 저장되는 항목 설명
* `id`: 프롬프트 고유 번호 (1, 2, 3... 순서대로 자동 증가)
* `title`: 프롬프트 제목 (필수 입력)
* `content`: 프롬프트 상세 내용
* `category`: 카테고리 (텍스트 생성, 이미지 생성, 영상 생성, 페르소나, 자동화, 기타)
* `favorite`: 즐겨찾기 여부 (참: ★ / 거짓: ☆)

## 🛠️ 5. 예외 처리 및 작동 규칙

1. **빈 제목 방지**: 프롬프트를 추가할 때 제목을 비워두고 엔터를 치면 등록되지 않고 다시 입력하라고 안내합니다.
2. **잘못된 입력 처리**: 메뉴 번호에 글자를 치거나 없는 번호를 눌러도 프로그램이 튕기지 않고 다시 안내 메시지를 띄웁니다.
3. **중복 처리**: 제목이 같은 프롬프트를 등록하더라도 고유 번호(`id`)가 다르게 부여되어 데이터가 섞이지 않습니다.
4. **검색 방식**: 대소문자 구분 없이 내가 입력한 단어가 제목이나 내용에 포함되어 있는지만 단순 비교하여 찾아냅니다.
5. **반복문 사용 이유**: 사용자가 종료를 원할 때까지 프로그램이 꺼지지 않고 계속 메뉴를 보여주기 위해 반복문(`while`)을 사용했습니다.

* **JSON 추천 이유**: 파이썬에서 제공하는 딕셔너리 구조와 제일 똑같이 생겨서 데이터를 읽고 쓰기가 가장 쉽고 깔끔합니다.
