# 📝 나만의 프롬프트 관리자 (Prompt Manager)

파이썬 콘솔(CLI) 환경에서 자주 사용하는 AI 프롬프트를 효율적으로 저장, 조회, 검색 및 즐겨찾기 관리할 수 있는 가벼운 프롬프트 관리 프로그램입니다.

---

## 🚀 실행 방법

### 1. 요구 사항
* Python 3.8 이상

### 2. 프로그램 실행
터미널(Terminal)에서 아래 명령어를 입력하여 프로그램을 실행합니다.

```bash
python main.py
```

---

## ✨ 주요 기능

| 번호 | 기능 | 설명 |
| :--- | :--- | :--- |
| **1** | **프롬프트 추가** | 제목, 내용, 카테고리를 입력 받아 새로운 프롬프트로 등록합니다. (ID 자동 부여) |
| **2** | **프롬프트 전체 목록** | 등록된 모든 프롬프트의 ID, 즐겨찾기 여부(★/☆), 제목, 카테고리를 한눈에 확인합니다. |
| **3** | **카테고리별 조회** | 지정한 카테고리에 속한 프롬프트만 모아서 필터링 조회합니다. |
| **4** | **프롬프트 검색** | 제목 및 내용에 특정 키워드가 포함된 프롬프트를 검색합니다. |
| **5** | **상세 보기** | 선택한 ID의 프롬프트 상세 내용 및 등록 정보를 확인합니다. |
| **6** | **즐겨찾기 토글** | 프롬프트의 즐겨찾기 상태를 등록(★) 또는 해제(☆)로 변경합니다. |
| **7** | **즐겨찾기 목록** | 즐겨찾기(★)로 지정된 중요한 프롬프트만 필터링하여 조회합니다. |
| **0** | **종료** | 프로그램을 안전하게 종료합니다. |

---

## 🏷️ 프롬프트 카테고리

프로그램에서 지원하는 6가지 프롬프트 카테고리 설명입니다.

* **텍스트 생성**: 블로그 글, 에세이, 마케팅 문구, 번역 등 글 작성 관련 프롬프트
* **이미지 생성**: 미드저니(Midjourney), DALL-E, 스태블 디퓨전 등 이미지 생성 AI용 프롬프트
* **영상 생성**: AI 비디오 생성, 영상 콘티 및 스토리보드 작성용 프롬프트
* **페르소나**: 특정 전문가, 캐릭터, 인물 역할을 부여하는 롤플레잉(Role-play) 프롬프트
* **자동화**: 코드 작성, 리팩토링, 데이터 정리 등 업무 자동화 및 개발 지원 프롬프트
* **기타**: 위 카테고리에 분류되지 않는 기타 일반 목적의 프롬프트
